Quantitative Residual-Risk Validation for SOTIF - LaTeX source

Compile with XeLaTeX, twice (second run fills the table of contents and references):
    xelatex sotif_residual_risk_report.tex
    xelatex sotif_residual_risk_report.tex
pdfLaTeX does not work (fontspec / unicode-math). Needs TeX Live with Latin Modern OpenType fonts.

figures/   vector PDFs, regenerated by tools/gen_report_figs.py in the repository.
numbers.json  all numbers quoted from the synthetic example.
All example data are synthetic and illustrative.
